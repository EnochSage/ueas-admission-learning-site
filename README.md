# UEAS Admission Portal Learning Studio

[Open the learning website](https://enochsage.github.io/ueas-admission-learning-site/)

This public repository contains **only the learning website**: eight lessons, workflow diagrams, glossary, practice scenarios, knowledge checks, and meeting preparation. The site explains the University of Engineering and Agricultural Sciences (UEAS) Admission Portal for Application Operations and Service Coordination.

## Source manuals

The original manuals and supporting files remain in the [private source repository](https://github.com/EnochSage/ueas-admin-portal-manual). GitHub sign-in and repository access are required:

- [Admission Portal Study Manual (HTML)](https://github.com/EnochSage/ueas-admin-portal-manual/blob/main/manuals/UEAS_Admission_Portal_Study_Manual.html)
- [Ghana UEAS Technical Manual (HTML)](https://github.com/EnochSage/ueas-admin-portal-manual/blob/main/manuals/UEAS-Technical-Manual.html)
- [CIS Completion Report (PDF)](https://github.com/EnochSage/ueas-admin-portal-manual/blob/main/manuals/UESD_CIS_Completion_Report_EN_Final_20260610.pdf)
- [Admission Portal screen reference (Word)](https://github.com/EnochSage/ueas-admin-portal-manual/blob/main/manuals/UEAS%20Admission%20Portal.docx)

The website cites relevant sections and pages, identifies observations and interpretations, and flags questions needing local verification. Its screenshots and learning content are published; the original source documents are excluded from this repository and from the Pages output.

Progress, bookmarks, quiz answers, and theme preferences are saved in the current browser only and do not synchronise across devices.

No open-source license has been added. The supplied university and project materials retain their existing rights.
